

# Jasd LifeOS – Personal Productivity App

**Jasd LifeOS** is a Flutter-based productivity system built for high-performance individuals who want to track tasks, goals, and workouts with a clean, intuitive interface. This is a solo portfolio build from the ground up: designed, scoped, and shipped by me, with no prior coding experience, using AI pair programming.

## 🚀 Features

- 🔁 Daily task tracking with streaks and progress bars  
- 🏋🏽 Workout logging, weekly goal tracking, and streaks  
- 📊 Dashboard with dynamic stats and visuals  
- 🎯 Vision setting + long-term goals tied to areas of life  
- 📈 Analytics page with charts (bar, pie, and line) for insights  
- ☀️ Light mode UI with modern FAANG-level design touches  
- 🔒 Local storage using SharedPreferences (for now)

## 📦 Tech Stack

- Flutter + Dart  
- SharedPreferences for local storage  
- fl_chart for analytics visualization

## 🧠 Why I Built It

I wanted a system that combined structure, intention, and momentum: something between Notion and Apple Health: but tailored to my real life. So I built it. LifeOS is my all-in-one dashboard for habit tracking, workouts, and personal goals.
